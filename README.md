# Mersenne Lab

Este repositorio está dedicado a la **Certificación Determinista de Primos de Mersenne** ($M_p = 2^p - 1$) utilizando el motor de alta integridad Antigravity.

## Arquitectura de Investigación
1. **P1 (Search)**: Búsqueda probabilística de alta velocidad (PRP).
2. **P2 (Verify)**: Certificación Lucas-Lehmer determinista.
3. **Audit**: Gobernanza mediante semáforo de integridad (Roundoff check).

## Estado de la Misión
Consultar `MERSENNE_OPERATIONAL_LOG.md` para el registro de exponentes certificados y misiones de fragilidad.
